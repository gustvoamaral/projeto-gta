# 🚗 Landing Page GTA

Este repositório contém o código-fonte de uma landing page inspirada no jogo **Grand Theft Auto V**.

## 🛠️ Tecnologias Utilizadas
- **HTML5** 
- **CSS3** 
- **JavaScript** 

## 📂 Estrutura do Projeto
```
/
|-- src/
|   |-- css/
|   |   |-- reset.css
|   |   |-- styles.css
|   |   |-- fontes.css
|   |   |-- responsive.css
|   |-- imagens/
|   |-- js/
|   |   |-- index.js
|-- index.html
```

## 🚀 Como Executar o Projeto
1. Clone este repositório:
   ```sh
   git clone https://github.com/gustvoamaral/projeto-gta.git
   ```
2. Acesse a pasta do projeto:
   ```sh
   cd projeto-gta
   ```
